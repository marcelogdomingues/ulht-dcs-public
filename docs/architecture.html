🎓 Core Services

Four specialized microservices working together to deliver secure digital credentials.

🎓

Student Service (Port 8084)

Entry point for credential issuance requests.

  • Request validation
  • Correlation ID generation
  • Kafka event publishing
  • Status monitoring
  • Consul service discovery
🏫

Lusofona Service (Port 8085)

ULHT API integration and student data retrieval.

  • Student authentication
  • ULHT API integration (SIGES)
  • Student data transformation
  • Comprehensive error handling
  • Consul service discovery
🎯

Credential Service (Port 8086)

W3C Verifiable Credential issuance using walt.id.

  • Generic YAML-based credential templates
  • walt.id integration
  • Dynamic field mapping
  • Conditional issuance
  • Consul service discovery
📦

Fulfilment Service (Port 8087)

Workflow tracking and progress monitoring.

  • Real-time progress tracking
  • Credential storage
  • SSE notifications
  • Workflow history
  • Consul service discovery

🔄 Workflow Flow

Event-driven credential issuance workflow across all services.

Step-by-Step Process

  1. Student Login (Mobile App) → POST http://localhost:8000/api/v1/students/issue (via Kong Gateway)
  2. Kong API Gateway → Routes request → Applies rate limiting & CORS
  3. Student Service → Validates request → Publishes to Kafka: student.login.requested
  4. Lusofona Service → Authenticates student → Fetches data from ULHT API → Publishes to Kafka: credential.requests
  5. Credential Service → Issues W3C credentials → Publishes progress updates → Publishes to Kafka: credential.completed
  6. Fulfilment Service → Tracks progress → Stores results → Sends SSE notifications
  7. Student Gets Credentials → OpenID credential offer URLs
💡 Note: All services register with Consul for service discovery. Kong Gateway routes requests based on service discovery.

📨 Kafka Topics

Event-driven communication using standardized Kafka topics with domain.action naming.

📤

Active Topics

  • student.login.requested - Student Service → Lusofona Service
  • credential.requests - Lusofona Service → Credential Service
  • credential.progress - Credential Service → Fulfilment Service (20%, 40%, 60%, etc.)
  • credential.completed - Credential Service → Fulfilment Service (with URLs)
  • credential.error - Credential Service → Fulfilment Service
🔄

Event Processing

  • Asynchronous processing for scalability
  • Correlation IDs for request tracking
  • Progress updates at each workflow step
  • Comprehensive error handling
  • Real-time SSE notifications
