🚀 Quick Start

Get up and running with the ULHT Digital Credential Service in minutes.

💡 Tip: Issue your first credential in just 3 steps!

1. Start Infrastructure

# Start infrastructure (Kafka, Consul, Kong, Monitoring) docker-compose -f docker-compose.infrastructure.yml up -d # Start microservices docker-compose -f docker-compose.microservices.yml up -d # Or start everything at once docker-compose up -d

2. Verify Services

# Check service health curl http://localhost:8084/actuator/health curl http://localhost:8085/api/v1/actuator/health curl http://localhost:8086/api/v1/actuator/health curl http://localhost:8087/api/v1/actuator/health

3. Issue Your First Credential

# Via Kong API Gateway (recommended) curl -X POST http://localhost:8000/api/v1/students/issue \ -H "Content-Type: application/json" \ -d '{"userName": "a12345678", "installKey": "00000_0000000000000"}' # Or directly (bypassing Kong) curl -X POST http://localhost:8084/student/issue \ -H "Content-Type: application/json" \ -d '{"userName": "a12345678", "installKey": "00000_0000000000000"}'

🏗️ Microservices Architecture

Four specialized services working together to deliver secure digital credentials.

🎓 Student Service (Port 8084)

Entry point for credential issuance requests with validation and Kafka event publishing.

  • Request validation
  • Correlation ID generation
  • Status monitoring endpoints
  • Consul service discovery

🏫 Lusofona Service (Port 8085)

ULHT API integration for student authentication and data retrieval from SIGES.

  • Student authentication
  • Academic data retrieval
  • Data transformation
  • Consul service discovery

🎯 Credential Service (Port 8086)

W3C Verifiable Credential issuance using walt.id with generic YAML-based templates.

  • Generic credential system
  • walt.id integration
  • Multiple credential formats
  • Consul service discovery

📦 Fulfilment Service (Port 8087)

Workflow tracking and progress monitoring with real-time updates via SSE.

  • Progress tracking
  • Result storage
  • SSE notifications
  • Consul service discovery

⚙️ Infrastructure Services

Modern infrastructure stack providing API gateway, service discovery, and messaging.

🛡️ Kong API Gateway

Ports: 8000, 8001

Centralized API gateway with routing, rate limiting, and CORS support.

  • Request routing
  • Rate limiting
  • CORS configuration
  • Request/response transformation

🔍 Consul

Ports: 8500, 8600

Service discovery and configuration management for microservices.

  • Service registration

Ports: 9092, 29092, 2181

Event-driven messaging platform for asynchronous communication.

  • Consumer groups
